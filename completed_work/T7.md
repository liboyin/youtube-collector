# T7: Make the written code standards executable

## Origin and boundary

From the 2026-11-07 project review of `ca869a8`. Ruff had no configuration, mypy ignored missing imports globally, and pytest neither rejected unknown markers nor turned warnings into errors, although AGENTS.md requires Google-style docstrings, lint limits and resolved warnings. Second commit of the T6/T7 group plan.

- **Intent:**
  - Ruff: 120-character lines; `E`, `W`, `F`, `I`, `B`, `UP` and `D` with the Google pydocstyle convention; the target Python comes from `requires-python`.
  - mypy: missing imports are errors.
  - pytest: `--strict-markers`, `filterwarnings = ["error"]` and `xfail_strict = true`.
  - Fix the violations the new rules find.
- **Revalidated deviation:** the TODO entry said "mypy ignores missing imports only for `yt_dlp`". With `warn_unused_configs`, an override for modules nobody imports prints an "unused section(s)" note on every run. Nothing imports `yt_dlp` or `pathlib_extensions` yet, and neither ships `py.typed` or stubs, so no override is added; a `pyproject.toml` comment gives the exact override for the change that first imports one. `youtube-transcript-api`, `fastapi`, `uvicorn` and `requests` ship `py.typed`.
- **Compatibility surface:** the conditions under which the lint, type and test gates fail. The review snapshot helper's behavior is unchanged. No application code exists.
- **Non-goals:** mypy strict mode, Ruff formatting or quote rules, further rule groups, application code.
