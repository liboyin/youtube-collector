# T11: Gap-review fixes for T2–T8

## Origin and boundary

The [grouped task execution](../.agents/skills/grouped-task-execution/SKILL.md) gap review of `47ac367..0ee004c` (2026-11-07) found one defect and four documentation nits; the user asked for all five to be fixed.

- **G1, defect:** a devcontainer built before `1674d93` keeps a Python 3.12 venv. There `uv lock --check --offline` failed, yet `./check-coverage.sh` passed the suite on the wrong interpreter. Fix: before pytest runs, the gate reads the first non-blank, non-comment line of `.python-version` in the working directory. It exits with a message unless `platform.python_version()` of the PATH `python3` equals that pin or starts with the pin plus `.`; a missing file or one with no version line also fails.
- **G2–G5, nits:**
  - DESIGN's status line said nothing was implemented.
  - T10 did not link T6 or check its removed packages.
  - TODO implied a standalone Compose binary was available.
  - TODO's dispositions were out of ID order.
- **Compatibility surface:** the coverage gate now refuses to run from a directory without `.python-version` and on a mismatched interpreter; README says to run it from the repository root. The mypy and Ruff gates are unchanged.
- **Non-goals:** interpreter checks in mypy or Ruff; changing how pytest is located.

## Implementation

- `check-coverage.sh`: the interpreter check, and a usage note in its header.
- `tests/tooling/test_check_coverage.py`:
  - The harness writes a matching major.minor pin by default.
  - New tests cover a matching full pin after comment and blank lines, and three non-matching pins: another major version, a minor that is only a string prefix (such as `3.1` for 3.14), and another patch release.
  - Further tests cover a missing file and a file with no version line.
- README Testing documents the check; DESIGN line 5 and TODO carry the nit fixes.

## Mutation evidence

Required: the check protects the gate against a false pass. The main agent was the primary producer.

Each mutant ran in its own copy inside the chroot, with `python -m pytest --no-cov -q -p no:randomly -p no:cacheprovider tests/tooling/test_check_coverage.py`. The tests load the script from the mutated copy through their `parents[2]` path. Each mutant changed one line:

- **Without `|| exit 1` after the version check:** pytest ran despite a mismatch, and five tests failed (the three mismatch cases and both unusable-file cases).
- **`actual.startswith(pin)` instead of `startswith(f'{pin}.')`:** the string-prefix case failed.
- **Without the exact-match branch:** the full-pin test failed.
- **Without skipping comment lines:** the full-pin test and the no-version-line test failed.

The reviewer verified each kill and its provenance, and added three passing probes of first-line and whitespace handling.
