# T16: Caption language matching

## Origin and boundary

Planned by [T9](T9.md). The accepted boundary, as it stood in TODO:

- **Intent:** DESIGN 5.6 with C12: well-formed language candidates, and the selection of at most one caption track.
- **Implementation direction:** `is_well_formed(tag)` matches RFC 5646 section 2.1's `Language-Tag` ABNF case-insensitively, including private-use and grandfathered tags, without registry checks: well-formed, not valid, as DESIGN requires. `select_track(candidates, tracks)` takes ordered candidates and the listed tracks, each exposing `language_code` and `is_generated` (the attribute names of `youtube-transcript-api`'s `Transcript`, described by a `Protocol`), and returns the chosen track or `None`. A candidate matches a code when its subtags, compared case-insensitively, are a prefix of the code's subtags. Candidates are tried in order against manual tracks, then in order against generated ones; within one candidate and kind an exact match wins, then listed order. The selector chooses only among the tracks it is given; T20 passes listed tracks and never translations, which satisfies rule 5.
- **Compatibility surface:** the later `languages` request field and the recorded track code and kind (T19, T24).
- **Non-goals:** normalizing codes (such as `iw` to `he`), BCP/ISO conversion and the source revision's whitelist, which stay in `youtube-whisperer`.
- **Validation:** tests for the ABNF's productions and rejections, every example in DESIGN 5.6 rule 1, no shorter-tag fallback, manual-first across the whole list, exact-before-listed order, and empty results. Mutation evidence for manual-first ordering and for the subtag boundary.

## Implementation

`youtube_collector/languages.py`: `is_well_formed` (one case-insensitive, ASCII-only regular expression for RFC 5646's `Language-Tag`, with the grandfathered and private-use alternatives), the `CaptionTrack` protocol and the generic `select_track`. `tests/test_languages.py`: 70 cases, using a frozen dataclass as the track.

## Mutation evidence

The main agent was the primary producer, with the same isolation, command and provenance check as [T15](T15.md#mutation-evidence), on `tests/test_languages.py`. Baseline: 70 passed.

- **T16-M1, candidate-first instead of manual-first:** the loops were swapped so each candidate tried manual and then generated tracks before the next candidate. `test_select_track_prefers_manual_tracks_across_the_whole_list` failed.
- **T16-M2, string prefix instead of subtag boundary:** `_matches` returned `code.lower().startswith(candidate.lower())`. `test_select_track_requires_every_candidate_subtag[zh-CNX]` and `test_select_track_respects_subtag_boundaries` failed.
- **T16-M3, no exact-match preference:** `return matches[0]`. `test_select_track_prefers_exact_match_then_listed_order` failed.
- **T16-M4, fallback to the primary subtag:** `_matches` also accepted a code equal to the candidate's first subtag. `test_select_track_requires_every_candidate_subtag[zh]` and `test_select_track_falls_back_only_to_later_candidates` failed.

Integrity snapshots matched. Verdict: no blocking findings, no Non-blocking findings or Nits.

## Limitations

- Rule 5 (auto-translated tracks are never selected) holds only if the caller passes listed tracks alone; T20 owns that.
