# T56: Stop a nested pytest's output from making a mutation run INVALID

**Priority:** Low.

Make `mutate.py` count only its own pytest's errors. Evidence: validated during [T54](../closed/T54.md#mutation-evidence). `run_tests` in `.agents/skills/adversarial-review/references/mutate.py` reads every output line that starts with `ERROR` as an errored test. A selected test that starts a nested pytest can print such a line into the outer failure report, and the run then counts as INVALID although the mutant was killed by a behavioral failure. The weakness errs toward INVALID, never toward KILLED. Paths: `.agents/skills/adversarial-review/references/mutate.py`, `tests/tooling/test_review_tools.py`. Outcome: the verdict uses the errors that the tool's own plugin reports for its own session, not lines matched in the output. Validation: a mutant whose observing test starts a nested pytest that prints an `ERROR` line is KILLED, and a genuine error in the outer session is still INVALID. Dependencies: none.
