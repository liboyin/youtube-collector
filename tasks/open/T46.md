# T46: Adapter contract tests against the real libraries

**Priority:** Medium. Decided by DESIGN C58; first raised in the 2026-11-10 review and still open at `4303fe5`.

Evidence: validated by reading the tests. `tests/test_captions.py` exercises `CaptionClient` only with fake transcript objects, so the real `youtube-transcript-api` parser, its error mapping and `SRTFormatter` on real payload shapes are untested. `tests/test_youtube.py` has one test that runs real yt-dlp against a loopback server, but it downloads a single combined format; the two-stream download and ffmpeg merge that production uses (`bestvideo[ext=mp4]+bestaudio[ext=m4a]`) run only in manual T25 runs.

Outcome: two groups of offline contract tests. For media, a loopback server offers separate tiny video and audio streams, generated by the test with the image's ffmpeg, in a form the locked yt-dlp treats as separate formats; `YoutubeClient.download_media` then selects both, merges them and leaves one playable MP4 at the literal target path, including a path containing `%`. For captions, owned fixture responses are served to the real `YouTubeTranscriptApi` through the injected HTTP session, covering a manual track, a generated track, disabled captions, a malformed payload and an HTTP failure, and asserting the SRT text and the exception types the worker relies on.

Constraints: no request may leave loopback ([AGENTS](../../AGENTS.md#tests)); the transcript client addresses YouTube's hosts, so the test routes them to loopback inside the session it injects rather than patching global state. Fixtures are hand-written or synthetic, not recordings of real account data, and are static files the tests only read. Servers and threads use the `loopback_server` and `owned_threads` fixtures.

Paths: `tests/test_youtube.py`, `tests/test_captions.py`, fixture files under `tests/`, `tests/README.md` if a convention is added. Compatibility surface: none; tests only. If the tests expose an adapter defect, record it and confirm scope with the user before fixing it here.

Validation: each new test fails when the behavior it protects is broken, shown for at least the merge (for example by removing `merge_output_format`) and for the error mapping. Dependencies: none. If [T51](T51.md) lands first, write the caption tests against its interface.
