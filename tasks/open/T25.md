# T25: First end-to-end run against real YouTube

**Priority:** Low.

First end-to-end run against real YouTube. Evidence: planning step; nothing in the automated suite contacts YouTube, so the adapters' assumptions about yt-dlp and caption responses are unverified against the live service. Paths: none expected; results go into this task's record. Outcome: a manual run of one short video and one short playlist through the service, following both workflows in DESIGN section 3. The run also checks what only the real share and YouTube can show: that files publish on the SMB share at all, because `StagedFile`'s `NEVER` policy uses a hard link with no fallback, so a share without hard links would fail every item; that playlist folder names survive there; that `<id> - <title>` names are recognized on a second submission, which should report `existing` with no download; and that `/health` stays healthy through a real download, including its ffmpeg merge (C43). Validation: the user authorizes the run and the videos ([AGENTS](../../AGENTS.md#safety)), and the outcomes, files and failures match DESIGN. Dependencies: [T33](../closed/T33.md), and the user's authorization for that run.
