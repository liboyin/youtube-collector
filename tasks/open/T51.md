# T51: Give the caption adapter one method and drop the track protocols

**Priority:** Low. Simplification from the 2026-11-14 review; internal only.

Evidence: validated by reading the code at `4303fe5`. The worker calls `CaptionSource.find_track` and then immediately `fetch_srt` with the returned object, from which it reads only `language_code` and `is_generated`. Supporting that split are `worker.Track`, the identical `languages.CaptionTrack` (flagged as a duplicate in the 2026-11-10 review), a type parameter on `Worker` and on `CaptionSource`, and an unparameterized `CaptionSource` in `api.Components`. The library's own track object crosses into the worker, which [T39](T39.md) would have to undo when it changes the backend.

Outcome: the caption adapter exposes one operation that returns either nothing, meaning captions are disabled or no track matches, or a small value holding the SRT text, the track's language code and whether it was generated. `Worker` and `CaptionSource` lose their type parameter, `worker.Track` is removed, and `languages.select_track` keeps the one protocol it needs. Behavior is unchanged: the same outcomes, failure records, exception handling by job kind, and timeouts.

Before removing the split, account for what it carries, as [AGENTS](../../AGENTS.md#design-and-documentation) requires: an error while listing and an error while fetching are both caption-service errors today and must stay so; `unavailable` is decided before any fetch; the recorded track kind and code come from the selected track.

Paths: `youtube_collector/captions.py`, `youtube_collector/worker.py`, `youtube_collector/languages.py`, `youtube_collector/api.py`, their tests, `tests/lifecycle_service.py`, DESIGN section 14. Compatibility surface: none; Python modules are internal. Validation: the existing worker and caption tests, adapted, still distinguish every caption outcome; mypy passes without new ignores. Dependencies: none. Land before [T39](T39.md) and, if convenient, before [T46](T46.md); coordinate with [T41](T41.md), which edits the same worker function.
