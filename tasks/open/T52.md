# T52: Small cleanups from the 2026-11-14 review

**Priority:** Low. Each item is validated by reading the code at `4303fe5`; none is a defect in behavior.

In scope, internal only, each small enough to verify by its tests:

- The `get_job` route's docstring in `youtube_collector/api.py` says a job past its retention returns 404. Under C42 it stays readable until the next submission deletes it. Correct the docstring; this was also noted in the 2026-11-10 review.
- `Worker.paused` is read only by tests. Remove it and have the tests observe the pause through the step result or the staging check, unless [T42](T42.md) gives it a real reader.
- `_Runtime` keeps the API's store in `threading.local` although exactly one executor thread ever uses it. A plain attribute is enough; sqlite3's own thread check still catches misuse.
- `youtube.PlaylistVideo` and `store.PlaylistEntry` hold the same two fields and the worker converts one to the other. Keep one, or state why both are needed.

Recorded but out of scope until the user decides, because each changes a contract:

- `COLLECTOR_PORT` means the published host port in `docker-compose.yaml` and the listen port in `config.Settings`. Renaming either changes a setting.
- `items_by_job` duplicates the index that `UNIQUE (job_id, position)` already creates. Dropping it changes the schema, and under C44 that means a new schema version that refuses existing databases, so it is worth doing only together with another schema change.
- A `captions` job runs a full yt-dlp metadata extraction for the title before it knows whether any caption track exists. Looking for the track first would save one YouTube request per video without captions, but it changes which failure a broken extraction produces (DESIGN 5.7).
- An item's result exists in four shapes (`worker._Outcome`, `store.ItemResult`, the row, `responses._Item`) plus dictionaries the store builds and Pydantic validates again at request time. Tolerable at this size; revisit if the API grows.
- `--cov-fail-under` in pytest's `addopts` is [T14](T14.md).

Validation: the gates; for each removal, show that a retained test still fails when the behavior it protected breaks.
