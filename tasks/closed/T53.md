# T53: Say how to fix a test that reached beyond loopback

**Outcome:** Implemented as an ad-hoc change; the user waived the adversarial review.

## Origin and boundary

An ad-hoc change requested by the user on 2026-11-14, after the T45/T50 reflection. A test that takes its deliberate network refusals only after an assertion that can fail also fails at teardown, and the second failure hides the first; in T50 this made a mutation run invalid. [tests/README.md](../../tests/README.md#network) records the convention for agents writing tests; this change puts the remedy in the teardown failure itself, where an agent running the tests sees it.

- **Intent:** the `network_refusals` teardown failure in `tests/conftest.py` keeps naming the refused attempts and also says how to fix the test: give the code under test a fake or a loopback endpoint, or take deliberate refusals with `network_refusals.take()`, in a `finally` if an assertion can fail before then. `NetworkRefusals.take` documents the same.
- **Dependencies:** [T50](T50.md) (the network guard and its fixture).
- **Compatibility surface:** test-only. The message keeps its opening words, "The test tried to reach beyond loopback", which `tests/test_main.py` and `tests/tooling/test_fixtures.py` match. No application code, setting or contract changes.
- **Non-goals:** the lifecycle service's equivalent message in `tests/test_main.py` (`lifecycle.expect_refusals`) is unchanged; `mutate.py` does not explain why a run is invalid.
- **Validation:** the nested teardown test asserts the remedy is in the output, and fails without the new message; the gates pass.
- **Done:** gates passed; review waived by the user; committed.

## Implementation

- `tests/conftest.py`: the teardown assertion's message gains the remedy and a pointer to tests/README's Network section; `NetworkRefusals.take`'s docstring says when to call it in a `finally` and why.
- `tests/tooling/test_fixtures.py`: `test_a_swallowed_external_connection_fails_teardown` also asserts that the output contains `network_refusals.take(), in a finally`.
