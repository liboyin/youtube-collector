# T6: Narrow the FastAPI dependencies

**Outcome:** Implemented with `httpx2` instead of the proposed `httpx` for tests; gates and review passed.

## Origin and boundary

From the 2026-11-07 project review of `ca869a8`, which found that `fastapi[standard]` brought `fastapi-cloud-cli`, `sentry-sdk`, the OpenTelemetry SDK and exporter, and more into a LAN-only service.

- **Intent:** depend on `fastapi` and `uvicorn[standard]` at runtime and put the TestClient transport in the dev group. `pydantic-settings` is not declared, because nothing uses it yet.
- **Revalidated choice:** the TODO entry proposed `httpx` for tests. Locked Starlette (with fastapi 0.162.0) emits `StarletteDeprecationWarning: Using httpx with starlette.testclient is deprecated; install httpx2 instead`, and T7 makes warnings errors, so the dev group uses `httpx2`.
- **Compatibility surface:** the runtime dependency set and `uv.lock`. Dropped capabilities (the `fastapi` CLI, form parsing, email validation, templates) are unused; no application code exists yet.
- **Non-goals:** version changes to retained packages, tool settings (T7).

## Implementation

`pyproject.toml` runtime dependencies are `fastapi`, `pathlib-extensions`, `requests`, `uvicorn[standard]`, `youtube-transcript-api` and `yt-dlp[default]`; the dev group gains `httpx2`. `uv.lock` was regenerated with plain `uv lock`.

## Validation

Environment: the `ubuntu:26.04` chroot described in [T3](T3.md#validation), Python 3.14.4, 2026-11-07.

- Lock: 87 to 56 packages; none added; no retained version or source changed. Removed: agent-detector, detect-installer, dnspython, email-validator, fastapi-cli, fastapi-cloud-cli, fastar, googleapis-common-protos, httpcore, httpx, jinja2, markdown-it-py, markupsafe, mdurl, five OpenTelemetry exporter packages, opentelemetry-proto, opentelemetry-sdk, opentelemetry-semantic-conventions, protobuf, pydantic-extra-types, pydantic-settings, python-multipart, rich, rich-toolkit, rignore, sentry-sdk, shellingham and typer. `uv lock --check --offline` passed.
- With the dev venv synced from the new lock, a FastAPI app's TestClient request returned the expected JSON under `python -W error`, with `httpx` absent; fastapi 0.162.0, uvicorn 0.54.0, uvloop and httptools imported.
- `./check-coverage.sh` (55 tests, 100% statement and branch), `mypy youtube_collector` and `ruff check .` passed.
- Baseline: the gates passed at `1674d93` under Python 3.14.4 ([T3](T3.md#validation)).
