## Implementation

The review found defects in the ported tools. This commit fixes each one.

- **`mutate.py`:**
  - It records each target's text and mode before the baseline.
  - Before each mutant, it stops the batch if a test changed the target. Otherwise a mutant whose old text a test removed would do nothing, and the test's own change could count as a kill.
  - It restores the recorded text and mode, and refuses a target that is not a regular file.
  - It reads and writes a target with `newline=''`, so a mutant keeps CRLF line endings.
- **`worktree_gates.py`:**
  - The freeze stores each path as Git spells it, so `./path` no longer makes a valid worktree fail.
  - It refuses an empty path.
  - `--changed` names get the same normalization.
  - `--compare` and `--remove` refuse a freeze record whose path is absolute, climbs out of the worktree or is spelled otherwise.
- **Review skill:** the main agent freezes a candidate before dispatch, and the reviewer never freezes one, because the freeze writes the repository's Git metadata. The user reviewed and approved this governance diff on 2026-11-23.
- **Tests:** `tests/tooling/test_review_tools.py` covers each fix. The hard-link test changed in two ways. In its baseline case, the outside file now equals the candidate, so the new check lets the mutant run. Its probe also records a leak when it sees the mutation, because a later restore through the link could hide the leak.
