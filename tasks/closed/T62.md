# T62: Extract GitHub SSH setup from the devcontainer hook

**Outcome:** Both devcontainer variants use the extracted GitHub SSH setup through the shared creation hook.

## Origin and boundary

The user approved moving the GitHub host-key setup into a separate script.

- **Intent:** Make the setup sequence in the creation hook easier to scan.
- **Dependencies:** Both devcontainer variants call the same creation hook. The existing SSH agent forwarding policy is DESIGN decision C31.
- **Implementation direction:** Move the full SSH setup block into a Bash helper. Invoke it in the same place as the original block.
- **Assumptions:** The hook runs from the repository root. Both variants already rely on that working directory to invoke the hook and its shared-tool helper.
- **Compatibility surface:** Preserve the HTTPS request, host-key formatting, `~/.ssh` permissions, `known_hosts` write, diagnostics and failure propagation.
- **Non-goals:** Changes to forwarding, trust policy or file update behavior.
- **Validation:** Run the three gates, Bash syntax checks, the documentation check and an offline probe of the creation hook.
- **Mutation evidence:** Check that the probe rejects skipping host-key setup and changing the curl invocation to disable certificate verification.
- **Done:** Passing checks, an independent review and this record.

## Implementation

The creation hook calls `.devcontainer/setup-github-ssh.sh` before shared-tool setup. The helper runs the original SSH block with the hook's Bash error options.

The existing hook test copies the new helper into its temporary workspace. It still runs the full hook with local stubs and checks the resulting `known_hosts` file.

## Validation

The baseline at `b826e561a7265a730b2da5e9c6ae9e7682d6c00f` passed all three gates in Docker with Python 3.14.4. The coverage gate ran 763 tests with 100% statement and branch coverage.

An offline probe substitutes local commands for curl, uv, sudo, the vendor installers and shared-tool setup. It exercises successful setup, an empty key list, malformed metadata and a failed fetch without contacting GitHub.

The first candidate coverage run exposed a missing helper in the hook test's temporary workspace. The fixture now copies it, and the test passes with its original assertions.

The reviewed candidate passed the same three gates and all 763 tests. Coverage reached 100% for statements and branches. Bash syntax checks for both scripts, the shared documentation check and `git diff --check` passed.
